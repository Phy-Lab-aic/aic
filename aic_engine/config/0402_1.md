  제어 방식 변천

  시도 1: scipy L-BFGS-B 전역 IK
    → 문제: configuration jump (한 바퀴 회전)

  시도 2: Regularization term 추가
    → 부분 개선, 근본 해결 안됨

  최종: Jacobian resolved-rate control
    → 매 50ms tick마다 δq = J⁺ × error 로 조금씩 이동
    → configuration jump 불가능, 단위 테스트 PASS
